# EV Charging Stations — Data Storytelling Dashboard

Adrien ASSOUAD | adrien.assouad@efrei.net

One-line: Streamlit dashboard analyzing EV Charging Stations in France.

Dataset: data.gouv.fr - Base nationale des IRVE

Run (PowerShell):
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
